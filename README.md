# MentorNet

MentorNet is a database-centric career counseling and guidance platform that connects students with mentors, enables discussions, and supports structured mentorship sessions.

---

## 🚀 Features (DB-focused)

- Role-based users (Students, Mentors/Counselors, Moderators)
- Career communities and discussion posts
- Commenting and interaction system
- Counseling services offered by mentors
- Session booking and management
- Feedback and rating system
- Reporting and moderation workflow

## 🛠️ Tech Implementation

### Database
- MySQL
- Tables with Primary Keys, Foreign Keys
- Constraints (CHECK, UNIQUE)
- Indexing for performance

### SQL Operations
- Selection, Projection
- Joins (INNER, LEFT)
- Aggregation (COUNT, AVG)
- GROUP BY, ORDER BY
- Subqueries

### Application Layer
- UI built using Lovable / frontend framework
- Dynamic input-output interactions
- Simulated/connected backend for DB operations

### Triggers Implemented
- Rating validation (ensures rating is between 1–5)
- Prevent past session booking
- Automatic enforcement of data integrity
